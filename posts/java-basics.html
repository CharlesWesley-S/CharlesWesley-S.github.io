📘 Java 基本语法与变量

掌握 Java 的变量类型、输入输出与基础逻辑结构

1. Java 简介

Java 是一种强类型、面向对象的语言，具有“Write Once, Run Anywhere”的特性。它通过 JVM（Java 虚拟机）实现跨平台运行。

2. 变量与类型

在 Java 中，每个变量都必须声明类型。例如：

int age = 18;
double pi = 3.14159;
String name = "Charles Wesley";

Java 中的变量主要分为：

  • 基本类型（int, double, boolean, char 等）
  • 引用类型（String, 数组, 自定义类）

3. Scanner 输入

可以使用 java.util.Scanner 从控制台接收输入：

import java.util.Scanner;

public class InputDemo {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    System.out.print("请输入你的名字: ");
    String name = sc.nextLine();
    System.out.println("你好, " + name + "!");
  }
}

4. 条件与循环

Java 支持 if、switch、for、while 等控制结构：

for (int i = 0; i < 5; i++) {
  System.out.println("循环第 " + i + " 次");
}
