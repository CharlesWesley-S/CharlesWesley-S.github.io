# Charles Wesley — Personal Portfolio

A bilingual, cosmic-themed personal website exploring the intersection of **cybersecurity**, **AI agents**, and **quantum computing**.

## Live site

[charleswesley-s.github.io](https://charleswesley-s.github.io/)

## Structure

- `index.html` — personal homepage, research interests, selected work, and GitHub activity
- `projects.html` — bilingual project mission-control page
- `styles.css` — responsive cosmic visual system
- `app.js` — language switching, animated background, navigation, and live GitHub statistics
- `posts/` — existing notes and archived content

The language preference is stored locally in the browser, so switching between **English** and **中文** does not reload or leave the current page.
