# Charles Wesley — Personal Portfolio

A bilingual, cosmic-themed personal website exploring the intersection of **cybersecurity**, **AI agents**, and **quantum computing**.

## Live site

[charleswesley-s.github.io](https://charleswesley-s.github.io/)

## Structure

- `index.html` — personal homepage, research interests, selected work, and GitHub activity
- `projects.html` — bilingual project mission-control page
- `project.html?id=...` — reusable project progress, milestones, and roadmap view
- `notes.html` — bilingual searchable knowledge archive
- `styles.css` — responsive cosmic visual system shared by every page
- `app.js` — language memory, search, project data, animated background, navigation, and live GitHub statistics
- `posts/` — existing notes and archived content

Language preference is stored locally in the browser, so **English / 中文** remains consistent while navigating. Social links include [GitHub](https://github.com/CharlesWesley-S) and [Zhihu](https://www.zhihu.com/people/42-29-23-9-75).
